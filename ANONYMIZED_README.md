# ANONYMIZED_README.md

## What the Code Does

This repository contains scripts and resources for a comprehensive empirical study on software reproducibility and research artifact analysis. The codebase includes data processing, analysis, and reporting tools to evaluate, verify, and summarize the reproducibility status of research projects. It automates the collection, filtering, and assessment of project data, and generates outputs for further manual and automated verification.

## How to Run It

1. **Install Dependencies:**
   - Ensure you have Python 3.8+ installed.
   - Install required packages using:
     ```bash
     pip install -r requirements.txt
     ```

2. **Run Analyses:**
   - Main analysis scripts can be executed directly, for example:
     ```bash
     python run_complete_research.py
     ```
   - Other scripts (e.g., `analyze_languages.py`, `complete_filtering_analysis.py`) can be run similarly for specific analyses.

3. **Reproducibility Checks:**
   - Use `setup_reproducibility.py` and related scripts to prepare and check reproducibility status.

4. **LaTeX Paper Compilation:**
   - Navigate to the `docs/` folder and use the provided batch scripts (e.g., `compile_papers.bat`) to compile the LaTeX papers.

## How It Relates to the Paper

The codebase underpins the empirical study described in the associated paper. It automates the data collection, filtering, and analysis processes, and produces the results, figures, and tables reported in the manuscript. The scripts ensure that all reported findings are reproducible and that the research workflow is transparent and verifiable. Outputs generated by these scripts are directly referenced in the paper's results and supplementary materials.

## File-by-File Overview

Below is a summary of the main files, their content, requirements, and their role in the project:

### Python Scripts

- **analyze_languages.py**: Analyzes programming languages used in the dataset. Requires input data files. Useful for understanding language distribution.
- **clean_replication.py**: Cleans and preprocesses replication data. Ensures data quality for downstream analysis.
- **complete_filtering_analysis.py**: Performs comprehensive filtering analysis on the dataset. Requires preprocessed data. Useful for filtering studies.
- **complete_research_journey.py**: Orchestrates the full research workflow, combining multiple steps. Useful for end-to-end reproducibility.
- **comprehensive_full_analysis.py**: Runs the full analysis pipeline, aggregating results. Requires all dependencies and input data.
- **create_comprehensive_pr_dataset.py**: Generates a dataset of pull requests for analysis. Requires access to raw data sources.
- **fast_essential_analysis.py**: Provides a faster, essential subset of the full analysis. Useful for quick checks.
- **final_status_check.py**: Checks the final status of reproducibility and analysis steps. Useful for validation.
- **honest_analysis.py**: Conducts an "honest" analysis variant for comparison. Useful for robustness checks.
- **quick_reproducibility_check.py**: Rapidly checks reproducibility status. Useful for preliminary assessments.
- **run_complete_research.py**: Main entry point for running the complete research workflow. Requires all dependencies.
- **setup_reproducibility.py**: Sets up the environment and data for reproducibility checks. Should be run before analysis.
- **test_distribution_analysis.py**: Analyzes the distribution of test cases in the dataset. Useful for test coverage studies.

### Data Files

- **comprehensive_full_dataset_analysis.json**: Output of the full dataset analysis. Used for reporting and further analysis.
- **complete_filtering_analysis.json**: Results of the filtering analysis. Referenced in the paper.
- **COMPLETE_STUDY_RESULTS.json**: Aggregated results from the complete study. Central to the paper's findings.
- **final_verification_sample.csv**: Sample data for manual verification. Used for validation.
- **verification_complete_readable.csv**: Readable output for verification steps. Useful for transparency.

### Documentation

- **README.md**: Main project documentation.
- **ANONYMIZED_README.md**: This anonymized version for review or sharing.
- **REPRODUCIBILITY_GUIDE.md**: Step-by-step guide for reproducing results.
- **REPRODUCIBILITY_STATUS.md**: Status summary of reproducibility checks.
- **COMPLETE_PROJECT_SUMMARY.md**: High-level summary of the project and results.
- **observations.md**: Additional notes and observations from the study.

### LaTeX and Paper Files (in `docs/`)

- **final_paper.tex**, **MSR2026_COMPREHENSIVE_STUDY.tex**, etc.: Main LaTeX sources for the paper and supplementary materials.
- **references.bib**: Bibliography for the paper.
- **compile_papers.bat**, **texcompile.bat**: Batch scripts to compile LaTeX documents.
- **outputs/**: Contains generated figures, tables, and supplementary outputs for the paper.

### Requirements

- **requirements.txt**: Lists all Python dependencies required to run the scripts.

### Why These Files Are Useful

Each file is designed to automate, document, or validate a specific part of the research workflow. Together, they ensure that the study is reproducible, transparent, and that all results can be traced back to their source data and analysis steps. This structure supports both automated and manual verification, making the research robust and credible.
