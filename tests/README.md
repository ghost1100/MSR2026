# Tests Directory

This directory contains all testing and validation scripts for the MSR project.

## Test Files

- `test_*.py` - Various unit and integration tests
- `validate_agents.py` - Agent validation scripts
- `verify_system.py` - System verification scripts

## Usage

Run tests from the project root directory:

```bash
# Run individual tests
python tests/test_comprehensive.py
python tests/test_fast.py

# Run validation
python tests/validate_agents.py
python tests/verify_system.py
```

## Academic Note

These test files are included for reproducibility and validation purposes but are not part of the core research contribution. They ensure the reliability of the analysis pipeline and data processing functions.
